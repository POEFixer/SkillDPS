# Changelog

## 1.0.3

- Rebuilt with the updated plugin SDK headers (POEFixer 365 adds optional calls for UI control names, stash objects and tabs, wider entity scans and the host automation flag). No change in what the plugin does.

## 1.0.2

- The "?" next to a section title now sits in its own gap instead of on the section's line.
- Diagnostics now looks the same as in the other POEFixer plugins.
- The bottom of the settings tab names the plugin's original author, as in the other plugins maintained by POEFixer.

## 1.0.1

- First POEFixer release of Skill DPS.
- Much lighter on frame time: the skill bar is found once and remembered instead of being searched four times a second, and "Include minions" no longer reads every item on the ground.
- Works at 1440p and 4K: icon and label sizes now follow the game's resolution.
- If a game update moves where a bar slot keeps its skill, the plugin finds it again by itself and never shows a wrong number meanwhile.
- New look for the numbers: adjustable size, background, position and colours, with a dark outline for readability; drawn under the POEFixer menu.
- The DPS list is a movable panel (drag it while the settings tab is open) with size and opacity settings and compact numbers (12.3k, 4.56M).
- Redesigned settings tab; diagnostics moved into one collapsed card.

## 1.0.0

- Original release by Ömer Faruk Arpa.
